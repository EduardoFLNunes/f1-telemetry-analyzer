# Geometria de Pista

**Uma filosofia visual para movimento plano: cor chapada, forma exata, ritmo de cronômetro.**

Tudo nasce de formas inteiras e sem sombra. Um círculo é um círculo, uma faixa é uma faixa, e nenhuma superfície finge volume. A profundidade vem da sobreposição honesta de planos de cor e da ordem em que eles entram em cena, nunca de gradientes ou brilhos. Cada elemento é construído com a paciência de quem desenha à régua: raios repetidos, espessuras iguais, ângulos que se respondem. O resultado deve parecer o trabalho minucioso de alguém no topo do ofício, que refez cada curva até ela assentar.

A cor é um sistema de sinais, não decoração. Há um fundo escuro de asfalto e um fundo claro de papel, alternados como capítulos. Sobre eles, poucas cores com papéis fixos e inegociáveis: uma cor para a referência, uma para quem aprende, uma para o que passou, uma para o que falhou, uma para a dúvida. Uma vez atribuída, a cor nunca troca de sentido. A paleta é calibrada com rigor quase obsessivo, para que dois tons que precisam ser distinguidos também difiram em claridade, e não só em matiz.

O espaço respira. Cada quadro tem uma ideia, ocupando uma área generosa, cercada de vazio deliberado. A composição prefere o eixo horizontal, como uma reta de chegada, e deixa a faixa inferior livre para a palavra escrita. Nada encosta na borda; nada se sobrepõe por acidente. A grade é invisível, mas sente-se em cada alinhamento, como resultado de incontáveis ajustes de poucos pixels.

O movimento tem a disciplina de uma volta cronometrada. As entradas são curtas e decididas, com um leve excesso que assenta, como um carro que freia no ponto. As saídas são mais rápidas que as entradas. Linhas se desenham no sentido da leitura; pontos caem e se alinham; números contam até o valor medido e param. A transição entre capítulos é uma faixa de cor que varre a tela inteira, sempre na mesma direção, para que o olho aprenda o ritmo.

O texto é escasso e funciona como sinalização de pista. Títulos condensados e altos, quase arquitetônicos; frases de apoio em um tipo pensado para ser lido por qualquer pessoa, em qualquer tela; números em fonte monoespaçada, alinhados como numa folha de tempos. Nunca um parágrafo onde uma forma resolve. A palavra entra para ancorar o que a forma já mostrou.

O conjunto deve ter o acabamento de uma peça mestra: cada ícone com o mesmo peso de traço, cada pausa medida no quadro, cada cor no lugar exato. Precisão sem frieza, clareza sem simplismo, o tipo de cuidado que só aparece depois de muitas horas de lapidação.
